Notação no JSON

Chavez {}
 usa-se para iniciar os objetos ou conjuntos de dados.
Colchetes []
 servem para iniciar um array (lista)
Dois pontos :
 separa a chave de seus valores correspondentes 
Virgula ,
 usa-se para separar cada  elemento contido em nosso objeto
